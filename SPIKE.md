# Спайк: iPhone + Telegram (стоп / идти)

Миниапп — это веб. Пока этот протокол не пройден на реальном iPhone, не считать Telegram-канал готовым к друзьям.

Спайк уже встроен в приложение (`/?spike=1`, либо долгое нажатие на `v 1.7.5` на домашнем экране).

## Подготовка

1. Собрать `flutter build web --release`.
2. Выложить по HTTPS (GitHub Pages / Cloudflare Pages / любой хост).
3. В BotFather привязать Mini App URL (см. `bot/BOTFATHER.md`).
4. Открыть миниапп **из Telegram на iPhone**, не из Safari.

## Чеклист

1. **Клавиатура.** На спайк-экране ввести вес (цифры) и заметку. Фокус, зум, клавиатура не должны ломать вёрстку так, что поле не видно.
2. **Локальная запись.** Save locally → Reload from device. Число на месте. `kv: device_storage` — хорошо. `shared_preferences` внутри Telegram iOS — плохо (кэш WebView).
3. **Первый офлайн.** После того как миниапп уже открывался с сетью: авиарежим, убить Telegram, открыть снова.
   - Оболочка открылась без вечной загрузки — идём дальше.
   - Белый экран / «нет сети» — Play остаётся подвальным клиентом, Telegram только с сигналом.
4. **Данные после убийства.** Вес со спайка всё ещё на экране.
5. **Бандл.** Первая загрузка на LTE. Если дольше ~10–15 с на среднем iPhone — предупреждать друзей, не обещать «как APK».
6. **Таймер.** В обычном приложении открыть тренировку, старт отдыха. Звук может не играть до жеста пользователя — это ограничение WebView, не блокер.

## Решение

- Все пункты 1–4 зелёные → масштабируем фичи.
- Провал 1 или 3 → не звать друзей, пока не сменим оболочку (не Flutter web) или не примем «нужен интернет в зале».
